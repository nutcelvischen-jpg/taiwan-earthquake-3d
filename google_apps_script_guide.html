🚀 後端部署指南

Google Apps Script (GAS) 地震小幫手快速部署

只需 2 分鐘，即可免費將地震小幫手後端掛上 Google Apps Script，獲得專屬 API 網址並串接至 3D 地圖！

← 返回 3D 臺灣地震儀表板
1
前往 Google Apps Script 建立新專案

1. 打開瀏覽器前往 Google Apps Script 主控台。
2. 點擊左上角的 「＋ 新專案」。
3. 將專案名稱重新命名為 臺灣地震3D智慧小幫手。

2
貼上程式碼 (Code.js)

清空 Code.gs 檔案原本的內容，點擊下方按鈕複製完整程式碼並貼入：

正在載入程式碼...
3
設定指令碼屬性 (填入 OpenRouter API Key)

為了保障 API Key 安全且不寫死在程式碼中，請透過 Apps Script 內建的屬性管理：
1. 點擊左側齒輪圖示 ⚙️ 「專案設定 (Project Settings)」。
2. 往下拉找到 「指令碼屬性 (Script Properties)」 ➔ 點擊 「新增指令碼屬性」。

屬性 (Property)： OPENROUTER_API_KEY
值 (Value)： sk-or-v1-xxxxxxxx... (貼上您的 OpenRouter API 金鑰)

點擊「儲存指令碼屬性」。這樣後端就能自動調用 Gemini 2.5 Flash 產生動態時空分鏡！

4
發布為 Web 應用程式 (Web App)

1. 點擊右上角藍色按鈕 「部署」 → 選擇 「新增部署作業」。
2. 點擊左側齒輪 ⚙️ → 選擇 「網路應用程式 (Web App)」。
3. 執行身分：選擇 我 (您的 Gmail)。
4. 誰可以存取 (關鍵！)：務必切換為 任何人 (Anyone)。
5. 點擊「部署」，並複製產生的 「網頁應用程式網址 (Web App URL)」。

5
回貼到 3D 地球儀設定中

回到 taiwan_earthquake_3d.html，點擊右上角 「⚙️ 小幫手設定」，將您的 GAS 網址貼入即可！
